## Why I Built This

I was watching YouTube when I came across a video of someone typing Java, Rust(its getting popular bruh!) and C++. It made me want to code something I hadn't touched before.

I thought of Why not something like Java GUI or JavaFX Initially it was Java GUI LOl!

I kept scrolling and found a video where [Ryan](https://github.com/BracketCove) teaches how to build a Sudoku game in Java.

Why not, right? I coded along with him and learned a lot! Even if i did not know how to initialize a pop.xml file

## What I Learned

* How to set up a project with Maven and JavaFX lib/
* How to work with JavaFX windows
* How to use JavaFX pieces like colors, rectangles and text boxes
* How to use the JavaFX buildIn classes
* How to addAll() and arrange UI components
* How to think before I code, then implement
* How to use a HashMap in a real project
* Many different ways to implement logic, userInterfaceImpl, BuildLogic, Testing etc

## How to Run

### Desktop (JavaFX)
```bash
mvn javafx:run
```
*Or open the project in IntelliJ IDEA and run [Main.java](src/main/java/sudoku/Main.java).*

## Tech Stack

* Java 25 LTS
* JavaFX
* Maven
